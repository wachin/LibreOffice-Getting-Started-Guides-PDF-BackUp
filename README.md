# LibreOffice "Getting Started" Guides — PDF Backup

A personal backup of the LibreOffice **Getting Started** guide PDFs, downloaded
from the official LibreOffice documentation site.

- **Source:** https://books.libreoffice.org/en/
- **Publisher:** The Document Foundation / LibreOffice project

## Contents

| File | Size | Description |
|------|------|-------------|
| `GS262-GettingStarted.pdf` | ~24 MB | LibreOffice *Getting Started* guide |
| `books.libreoffice.org URL.txt` | 34 B | The source URL, kept for reference |

## Purpose

This repository is a **backup** of the LibreOffice guides. It is also used as
**test material** for large / heavy PDF documents — for example, to exercise
the performance (fast loading, smooth scrolling, tiled rendering) of PDF
readers such as [PDF-Advanced-Reader](https://github.com/wachin/PDF-Advanced-Reader).

> `GS262-GettingStarted.pdf` is a large, heavy document, which makes it well
> suited for performance and rendering tests.
